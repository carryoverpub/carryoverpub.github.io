# carryover.pub

The site of the paper *Carryover Effects in Reused KV Caches Across Agent Handoffs and Policy Updates*.
One static page, no build step. Every figure on the page stands on a named entry and line of one of the two public records:
[linear-ceiling](https://github.com/hossainpazooki/linear-ceiling) (text axis) and [lag-ladder](https://github.com/hossainpazooki/lag-ladder) (weights axis).
Nothing on this page is computed here; a figure that changes re-enters only through a later entry on its ledger.
